NINJA SCHEDULE v9.1 静的確認結果

確認済み
- 月キャッシュがない場合のみ events API を自動実行
- 取得済み月への再移動では自動通信なし
- 手動「読込」は強制再取得
- 日付クリックと予定詳細表示は通信なし
- 出欠登録時のみ saveAttendance API 通信
- 出欠登録前の入力チェックあり
- 出欠登録成功後に myAttendance を端末キャッシュへ保存
- events API は選手カテゴリーで絞り込み
- events API は本人の保存済み出欠回答を付加
- 予定保存・削除の差分更新方式を維持
- 既存UI、添付、スワイプ機能を維持

本番環境で必要な確認
- Apps Script再デプロイ後の出席・遅刻・欠席登録
- LINE LIFFで月初回自動読込
- GitHub Pagesで取得済み月が再通信しないこと
